# CyberAcademy: Custom Blue Team Training Platform

A TryHackMe-style training platform focused on defensive security (blue team).
Built with Node.js, Express, MySQL and XAMPP.

## Features

- User registration and login (bcrypt-hashed passwords, server-side sessions)
- Personal dashboard: points, rank, completion %, progress per category, recent activity
- Labs with scenario instructions and flag submission (flags stored only as SHA-256 hashes)
- Submission history and progress stored in MySQL
- Leaderboard
- Kali Linux integration: students download each lab's evidence directly onto their **own** Kali VM and analyse it there, so no dedicated lab server is needed

## Included labs

| Lab | Category | Difficulty |
| --- | --- | --- |
| Detecting an SSH Brute-Force Attack | Log Analysis | Easy |
| Spotting SQL Injection in Web Logs | Log Analysis | Medium |
| Analysing a Phishing Email | Phishing & Email | Easy |
| Hunting Indicators of Compromise | Threat Hunting | Medium |

All evidence files (logs, a raw email, endpoint telemetry) are synthetic and generated by `generate-artifacts.js`. They use reserved documentation IP ranges and `.example` domains.

## Setup

### 1. Requirements

- [XAMPP](https://www.apachefriends.org/) (start the **MySQL** module)
- [Node.js](https://nodejs.org/) 18 or newer

### 2. Install

```bash
npm install
cp .env.example .env      # on Windows: copy .env.example .env
```

Edit `.env`:

- `SESSION_SECRET`: set a long random string
- `DB_*`: XAMPP defaults (user `root`, empty password) work as-is
- `LAB_HOST`: the IP of the machine running the platform **as seen from your Kali VM** (see below)

### 3. Create the database

Open phpMyAdmin (http://localhost/phpmyadmin), go to **Import**, and import `schema.sql`.
Or from a terminal:

```bash
mysql -u root < schema.sql
```

### 4. Seed the labs

```bash
node seed.js
```

This generates the evidence files into `lab-files/` and inserts the labs into the database.

### 5. Run

```bash
npm start
```

Open http://localhost:3000, create an account, and start on the **Labs** page.

## Connecting your Kali VM

1. In VirtualBox/VMware, put the Kali VM on a **Host-only** or **Bridged** network so it can reach your host machine.
   - Host-only (VirtualBox default): the host is usually `192.168.56.1`.
   - Bridged: use your host's LAN IP.
2. Set `LAB_HOST` in `.env` to that address and restart the server.
3. Allow inbound connections on port 3000 in your host firewall (Windows: "Allow an app" or add an inbound rule for TCP 3000, limited to the private network).
4. On Kali, test connectivity: `curl -I http://<LAB_HOST>:3000`
5. Open a lab, click **Generate download command**, and paste it into the Kali terminal. The link carries a personal token that expires after 4 hours.
6. Analyse the evidence with standard tools (`grep`, `awk`, `sort`, `uniq`, `less`, `cut`) and submit the flag on the lab page.

## Project structure

```
server.js              Express app: auth, dashboard, labs, submissions, downloads
db.js                  MySQL connection pool
schema.sql             Database schema
seed.js                Seeds labs (hashes the flags)
labs-data.js           Lab definitions, instructions and flags
generate-artifacts.js  Generates the synthetic evidence files
public/                Frontend (HTML, CSS, JS)
lab-files/             Generated evidence (created by seed.js)
```

## Adding a new lab

1. Add an entry to `labs-data.js` (slug, title, category, difficulty, instructions, flag, artifact filename).
2. Add a generator for its evidence file in `generate-artifacts.js`.
3. Run `node seed.js`. Existing labs are updated, new ones are added.

## Security notes

- Passwords are hashed with bcrypt; sessions use HttpOnly cookies.
- All database queries are parameterised.
- Flag submissions are rate limited (8 attempts per minute per lab).
- Only files listed in `labs-data.js` can be downloaded from `/lab-files/`.
- This is built for a trusted local or classroom network. Before exposing it to the internet, put it behind HTTPS and set `cookie.secure` in `server.js`.
